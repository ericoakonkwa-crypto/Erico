# Math Quiz Game 🎓

An interactive math quiz game where players answer questions on various topics and receive hints from Mr. Math!

## Features

- **Math Topics**: Addition, Subtraction, Multiplication, Division, BODMAS, Algebra, and Calculus
- **Teacher Character**: Mr. Math provides helpful hints for struggling players
- **Multiple Difficulty Levels**: Easy, Medium, Hard
- **Score Tracking**: Keep track of your performance
- **Hint System**: Get help from Mr. Math when you're stuck

## How to Run

```bash
python main.py
```

## Game Topics

1. **Addition** - Basic addition problems
2. **Subtraction** - Basic subtraction problems
3. **Multiplication** - Multiplication tables and problems
4. **Division** - Division problems with remainders
5. **BODMAS** - Order of operations (Brackets, Orders, Division, Multiplication, Addition, Subtraction)
6. **Algebra** - Solving for unknown variables
7. **Calculus** - Derivatives and integrals
